# Crear el sistema de textos en español e inglés

## Objetivo
Existe un módulo i18n con `t(clave, params)`, cambio de idioma, y textos repartidos en
diccionarios por sección que cada tarea de interfaz puede ampliar sin tocar archivos comunes.

## Archivos en alcance
- src/i18n/index.js (crear)
- src/i18n/sections/comun.js (crear)
- tests/i18n.test.js (crear)

## No tocar
- data/raw/

## Detalles
- Cada archivo de `src/i18n/sections/*.js` exporta por defecto `{ es: {...}, en: {...} }` con
  claves planas con punto (`'header.tema.oscuro'`). `index.js` los carga con
  `import.meta.glob('./sections/*.js', { eager: true })` y los fusiona en un diccionario por idioma.
- API de `index.js`:
  - `t(clave, params = {})`: devuelve el texto del idioma activo; reemplaza `{nombre}` por
    `params.nombre`. Si la clave no existe en el idioma activo, usa el español; si tampoco
    existe, devuelve la propia clave (nunca lanza).
  - `getLang()` y `setLang(lang)`: `lang` es `'es'` o `'en'`; otro valor se ignora.
    Idioma inicial `'es'`. `setLang` actualiza `document.documentElement.lang` y llama a los
    suscriptores.
  - `onLangChange(fn)`: registra un suscriptor y devuelve una función para cancelarlo.
  - `LANGS`: `['es', 'en']`.
- La persistencia en `localStorage` la hace la tarea 007; este módulo no la toca.
- `comun.js` incluye: `titulo` ("Local + Claude" en los dos idiomas), `subtitulo`
  ("¿Vale la pena delegar?" / "Is delegating worth it?"), `footer.leyenda`
  ("Hecho con Claude Code y SDD" / "Made with Claude Code and SDD"), `modo.local`,
  `modo.pareja`, `modo.claude` (etiquetas: "Modelo local solo" / "Local model only",
  "Pareja (local + revisión)" / "Pair (local + review)", "Claude solo" / "Claude only").
- Pruebas: `t` devuelve español e inglés tras `setLang`; sustituye parámetros; clave
  inexistente devuelve la clave; `setLang('fr')` se ignora; **paridad**: cada clave de `es`
  existe en `en` y viceversa, para el diccionario fusionado completo (esta prueba protege
  también las secciones que se agreguen después).
